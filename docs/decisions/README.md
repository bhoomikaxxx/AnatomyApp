# Decisions

One file per decision that would be expensive to re-litigate: `YYYY-MM-DD-<slug>.md`. Record the
options that were rejected and **why** — especially anything rejected by the platform or the compiler,
so nobody re-attempts it.

## Template
```markdown
# D-<ID> — <title>

**Direction (YYYY-MM-DD, <who>):** <what was asked for>

## Ruling
<what we chose, in one paragraph>

| Option | Verdict |
|---|---|
| <option> | <chosen / rejected — reason> |

## Consequences
<what this commits us to; what would make us revisit it>
```
